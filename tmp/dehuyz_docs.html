Dokumentasi REST API WAHub

Integrasikan layanan OTP otomatis ke dalam bot Telegram, script otomatisasi, atau aplikasi web Anda. Mendukung sistem Pay-per-Success (saldo hanya terpotong jika kode OTP berhasil diterima) dan Re-OTP Gratis.

🔑 Autentikasi

Setiap permintaan API wajib menyertakan header Authorization menggunakan Bearer Token (API Key) Anda. Dapatkan key unik Anda di Dashboard → API Keys. 

Authorization: Bearer wh_live_xxxxxxxxxxxxxxxxxxxxxxxx
GET

/api/services

Mendapatkan daftar semua layanan yang tersedia, harga sewa, dan jumlah stok nomor aktif saat ini.

Response (200 OK):

[
  {
    "id": 1,
    "name": "Shopee",
    "price": 2500,
    "stock": 15
  },
  {
    "id": 2,
    "name": "Gojek / Gofood",
    "price": 3000,
    "stock": 8
  }
]
GET

/api/balance

Memeriksa saldo akun. available adalah saldo bersih yang siap digunakan (balance - reserved).

Response (200 OK):

{
  "balance": 50000,
  "reserved": 2500,
  "available": 47500
}
POST

/api/rent

Menyewa nomor baru untuk layanan tertentu. Saldo akan ditahan sementara dan hanya terpotong permanen jika OTP berhasil diterima.

Request Body:

{
  "service_id": 1
}

Response Sukses (200 OK):

{
  "order_id": 105,
  "token": "wh_rnt_9f8a7b6c5d4e",
  "phone": "85196495750",
  "expires_at": 1735901200
}

💡 Gunakan token untuk mengecek OTP pada endpoint /api/sms/{token}.

GET

/api/sms/{token}?timeout=60

Menunggu & mengambil OTP yang masuk ke nomor sewa (Long-polling). Parameter timeout (opsional, default 60s, maks 120s).

Response OTP Berhasil Diterima (200 OK):

{
  "state": "success",
  "otp": "21412"
}

💡 Nilai otp berisi kode 4-8 digit angka yang diekstrak secara presisi. Saldo akun baru terpotong saat respon ini muncul.

POST

/api/rent/{token}/retry

Re-OTP Gratis: Meminta kode OTP ulang pada nomor & order yang sama (maksimum 5 kali per sewa). Tidak ada pemotongan saldo tambahan.

Response Sukses (200 OK):

{
  "order_id": 105,
  "token": "wh_rnt_9f8a7b6c5d4e",
  "phone": "85196495750",
  "expires_at": 1735901200
}

Setelah memanggil retry, lakukan poll ulang ke GET /api/sms/{token} dengan token yang sama.

GET

/api/order/{id}

Melihat status order milik Anda. {id} dapat berupa order_id atau token sewa; order selesai dan sudah diakui tetap dapat dilihat.

Response (200 OK):

{
  "order_id": 105,
  "token": "wh_rnt_9f8a7b6c5d4e",
  "phone": "85196495750",
  "service_id": 1,
  "service": "Shopee",
  "price": 3500,
  "state": "success",
  "otp": "21412",
  "expires_at": 1735901200,
  "created_at": 1735900000
}
POST

/api/order/{id}

Menjalankan aksi pada sebuah order. Aksi ditentukan lewat field action di body.

{id} menerima order_id (angka, dari response /api/rent) maupun token sewa.

Request Body:

{
  "action": "done"
}

Response Sukses (200 OK):

{
  "ok": true,
  "action": "done",
  "order_id": 105,
  "token": "wh_rnt_9f8a7b6c5d4e",
  "phone": "85196495750",
  "service": "Shopee",
  "price": 3500,
  "state": "success",
  "refunded": 0,
  "expires_at": 1735901200,
  "created_at": 1735900000
}

Aksi yang Didukung:

cancelMembatalkan order dan melepas nomor. Saldo yang masih ditahan dikembalikan 100%.
doneMengakui OTP yang sudah diterima, melepas nomor, dan tidak mengubah saldo maupun transaksi.

Gunakan done setelah state menjadi success. Nilai refunded akan selalu 0 untuk action ini.

DELETE

/api/rent/{token}

Legacy

Bentuk lama dari pembatalan sewa. Tetap didukung dan tidak akan dimatikan, jadi integrasi yang sudah jalan tidak perlu diubah.

Untuk integrasi baru gunakan POST /api/order/{id} di atas — response-nya memuat detail order dan jumlah refund, bukan hanya ok.

Response (200 OK):

{
  "ok": true
}

💻 Contoh Kode Integrasi Lengkap

Pilih bahasa pemrograman favorit Anda di bawah ini:

import requests

API_KEY = "wh_live_xxxxxxxxxxxxxxxxxxxxxxxx"
BASE_URL = "https://dehuyzotp.shop"
headers = {"Authorization": f"Bearer {API_KEY}"}

# 1. Sewa Nomor (misal Shopee, service_id = 1)
rent = requests.post(f"{BASE_URL}/api/rent", headers=headers, json={"service_id": 1}).json()
token = rent["token"]
order_id = rent["order_id"]
phone = rent["phone"]
print(f"Nomor disewa: {phone}")

# 2. Tunggu OTP masuk (Long-polling 60 detik)
sms = requests.get(f"{BASE_URL}/api/sms/{token}?timeout=60", headers=headers).json()
if sms.get("state") == "success":
    print(f"Kode OTP Masuk: {sms['otp']}")
else:
    # Pembatalan jika OTP belum masuk
    r = requests.post(f"{BASE_URL}/api/order/{order_id}",
                      headers=headers, json={"action": "cancel"}).json()
    print(f"Dibatalkan, refund Rp{r['refunded']}")
const API_KEY = 'wh_live_xxxxxxxxxxxxxxxxxxxxxxxx';
const BASE_URL = 'https://dehuyzotp.shop';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

async function main() {
  // 1. Sewa Nomor
  const rent = await fetch(`${BASE_URL}/api/rent`, {
    method: 'POST', headers, body: JSON.stringify({ service_id: 1 })
  }).then(r => r.json());

  console.log(`Nomor disewa: ${rent.phone}`);

  // 2. Tunggu OTP
  const sms = await fetch(`${BASE_URL}/api/sms/${rent.token}?timeout=60`, { headers }).then(r => r.json());
  if (sms.state === 'success') {
    console.log(`Kode OTP Masuk: ${sms.otp}`);
  }
}
main();

$apiKey = "wh_live_xxxxxxxxxxxxxxxxxxxxxxxx";

$sms = json_decode(curl_exec($ch), true);
curl_close($ch);

if (($sms["state"] ?? "") === "success") {

# 5. Batal Sewa — pakai order_id atau token

Daftar HTTP Status Codes & Error

Kode Keterangan Penjelasan
200 OK Sukses Permintaan berhasil diproses.
400 Bad Request Body / Action Tidak Valid JSON rusak, field action kosong, atau aksi tidak dikenal pada POST /api/order/{id}.
401 Unauthorized API Key Salah / Hilang Header Authorization: Bearer tidak valid atau kosong.
403 Forbidden Akun Diblokir Akun pengguna dalam status diblokir oleh admin.
404 Not Found Order Tidak Ditemukan Tidak ada order dengan id/token itu pada akun Anda, atau order sudah dalam status terminal.
408 Timeout Waktu Tunggu Habis Tidak ada OTP masuk hingga waktu timeout berakhir. Dapat dipoll kembali.
409 Conflict Rental Expired / Limits Sewa telah kedaluwarsa (20 menit) atau batas retry tercapai.
410 Gone Sewa Berakhir Order sudah dalam status terminal (success/cancelled/expired).
429 Rate Limit Max Concurrent Reached Batas maksimum sewa bersamaan telah tercapai. Hilangkan sewa lama lebih dulu.
503 Service Unavailable Stok Habis Tidak ada nomor aktif yang tersedia untuk layanan ini.
